Giáo trình Linux Command Line

Bản tóm lược tiếng Việt của cuốn The Linux Command Line. Mỗi chương gồm ý chính, lệnh cần nhớ kèm ví dụ, và 5 bài tập từ dễ đến khó kèm lời giải để bạn gõ thử ngay trên terminal (Linux, WSL hoặc macOS đều được, macOS có vài khác biệt nhỏ). Đánh dấu “Đã học” để theo dõi tiến độ.

          Phần 1

          Học shell

          Ngôn ngữ cơ bản của dòng lệnh: cấu trúc lệnh, di chuyển trong hệ thống file, chuyển hướng, mở rộng (expansion), quyền và tiến trình.

          01

          Shell là gì?

          Shell là chương trình nhận lệnh bạn gõ và chuyển cho hệ điều hành thực thi. Trên hầu hết Linux, shell mặc định là bash (Bourne Again SHell). Bạn mở shell qua một terminal emulator (GNOME Terminal, Konsole…).

          • Dấu nhắc user@host:~$: kết thúc bằng $ là người dùng thường, # là root (quản trị).
          • Phím ↑ ↓ duyệt lại lịch sử lệnh; ← → di chuyển con trỏ để sửa lệnh.
          • Gõ exit hoặc Ctrl+D để đóng phiên.
          $ date        # ngày giờ hiện tại
$ cal         # lịch tháng này
$ df          # dung lượng trống của các ổ đĩa
$ free        # bộ nhớ RAM trống
          02

          Di chuyển trong hệ thống file

          Linux tổ chức file thành một cây thư mục duy nhất bắt đầu từ gốc / (không có ổ C:, D: như Windows). Tại mỗi thời điểm bạn đứng ở một thư mục làm việc hiện tại.

          LệnhÝ nghĩa
          pwdIn thư mục hiện tại
          lsLiệt kê nội dung thư mục
          cd /usr/binĐường dẫn tuyệt đối (bắt đầu từ /)
          cd .. / cd ./binĐường dẫn tương đối: .. thư mục cha, . thư mục hiện tại
          cd · cd ~Về thư mục home
          cd -Quay về thư mục vừa ở trước đó
          cd ~bobVào home của user bob

          Lưu ý: tên file phân biệt hoa thường; file bắt đầu bằng dấu chấm (.bashrc) là file ẩn; tránh dùng dấu cách trong tên file, hãy dùng _ hoặc -.

          03

          Khám phá hệ thống

          Cú pháp chung của lệnh: lệnh -tùy_chọn đối_số. Tùy chọn ngắn có thể gộp (ls -lt), tùy chọn dài dùng hai gạch (--reverse).

          $ ls -l          # định dạng dài
$ ls -la         # kể cả file ẩn
$ ls -lh         # kích thước dễ đọc (K, M, G)
$ ls -lt --reverse  # sắp theo thời gian, đảo ngược
-rw-r--r-- 1 me me 32059 2026-11-20 10:12 notes.txt
# quyền  link chủ nhóm  size   ngày sửa       tên
$ file notes.txt    # cho biết loại file (text, ảnh, ELF…)
$ less /etc/passwd  # xem file văn bản từng trang

          Trong less: Space/b trang sau/trước, G cuối file, g đầu file, /từ tìm, n kết quả tiếp, q thoát.

          Các thư mục quan trọng: /bin /sbin (chương trình hệ thống), /etc (cấu hình), /home (dữ liệu người dùng), /root, /tmp, /usr (chương trình người dùng), /usr/local (phần mềm tự cài), /var (dữ liệu thay đổi, log ở /var/log), /dev (thiết bị), /proc (cửa sổ nhìn vào kernel), /boot, /lib, /media /mnt (điểm gắn ổ).

          Symbolic link (liên kết mềm) hiện trong ls -l dạng libc.so.6 -> libc-2.6.so: một tên trỏ đến file khác.

          04

          Thao tác với file và thư mục

          Wildcard giúp chọn nhiều file cùng lúc:

          MẫuKhớp với
          *Mọi chuỗi ký tự
          ?Đúng một ký tự
          [abc] · [!abc]Một ký tự trong tập / ngoài tập
          [[:digit:]] [[:upper:]] [[:alpha:]]Lớp ký tự: số, chữ hoa, chữ cái
          Data??? · *.html · [[:upper:]]*Ví dụ: “Data” + 3 ký tự, đuôi .html, bắt đầu bằng chữ hoa
          $ mkdir -p a/b/c          # tạo thư mục (cả cha nếu thiếu)
$ cp -i f1 f2             # chép, hỏi trước khi ghi đè
$ cp -r dir1 dir2         # chép cả thư mục
$ cp -u *.html dest/      # chỉ chép file mới hơn
$ mv old new              # đổi tên / di chuyển
$ rm -i file              # xóa có hỏi
$ rm -r dir               # xóa thư mục và mọi thứ bên trong
$ ln file hardlink        # hard link
$ ln -s file symlink      # symbolic link
          • Không có thùng rác trên dòng lệnh. Mẹo an toàn: thử wildcard bằng ls *.html trước rồi mới rm *.html. Cẩn thận lỗi gõ rm * .html (có dấu cách) sẽ xóa sạch thư mục.
          • Hard link: thêm một tên cho cùng dữ liệu (cùng inode, xem bằng ls -li); không trỏ tới thư mục, không vượt sang ổ khác. Symlink: file đặc biệt chứa đường dẫn tới file đích; xóa đích thì symlink thành “gãy”.
          05

          Làm việc với lệnh

          Một “lệnh” có thể là 4 thứ: chương trình thực thi (file trong /usr/bin), lệnh dựng sẵn của shell (builtin như cd), hàm shell, hoặc alias.

          $ type ls        # ls is aliased to `ls --color=auto'
$ type cd        # cd is a shell builtin
$ which ls       # /usr/bin/ls (chỉ với chương trình thực thi)
$ help cd        # trợ giúp cho builtin
$ mkdir --help   # hầu hết chương trình hỗ trợ --help
$ man ls         # trang hướng dẫn (manual)
$ man 5 passwd   # chọn section 5: định dạng file
$ apropos floppy # tìm lệnh theo từ khóa (= man -k)
$ whatis ls      # mô tả một dòng
$ info coreutils # tài liệu dạng info của GNU

          Tự tạo lệnh bằng alias; nhiều lệnh trên một dòng nối bằng dấu ;:

          $ alias foo='cd /usr; ls; cd -'
$ foo
$ unalias foo
$ alias            # xem tất cả alias

          Alias tạo trên dòng lệnh mất khi đóng shell; muốn giữ lâu dài thì ghi vào ~/.bashrc (chương 11).

          06

          Chuyển hướng và đường ống

          Mọi chương trình có 3 luồng: stdin (số 0, bàn phím), stdout (1, màn hình), stderr (2, màn hình). Ta có thể chuyển hướng chúng.

          $ ls -l /usr/bin > out.txt      # ghi đè stdout vào file
$ ls -l /usr/bin >> out.txt     # nối thêm
$ > out.txt                     # mẹo: làm rỗng file
$ ls /khongco 2> err.txt        # chuyển stderr
$ ls /bin /khongco &> all.txt   # cả stdout và stderr (bash)
$ ls /bin > all.txt 2>&1        # cách cũ; thứ tự quan trọng!
$ ls /khongco 2> /dev/null      # vứt bỏ lỗi ("thùng rác bit")
$ cat f1 f2 > merged            # cat nối file
$ cat < notes.txt               # lấy stdin từ file

          Pipeline | nối stdout của lệnh trước vào stdin của lệnh sau. Các lệnh đọc stdin, biến đổi rồi ghi stdout gọi là filter:

          $ ls /bin /usr/bin | sort | uniq | less
$ ls /bin /usr/bin | sort | uniq -d    # chỉ dòng trùng
$ ls /usr/bin | wc -l                   # đếm số dòng
$ ls /usr/bin | grep -i zip             # lọc dòng chứa "zip"
$ head -n 5 file ; tail -n 5 file
$ tail -f /var/log/syslog               # theo dõi log trực tiếp
$ ls /usr/bin | tee ls.txt | grep zip   # vừa lưu file vừa chuyển tiếp

          Lỗi kinh điển: dùng > thay cho | (lệnh1 > lệnh2) sẽ ghi đè lên file tên lệnh2. Đừng làm thế trong /usr/bin với quyền root.

          07

          Nhìn thế giới như shell nhìn

          Trước khi chạy lệnh, shell mở rộng (expansion) những gì bạn gõ. Dùng echo để thấy kết quả mở rộng.

          LoạiVí dụKết quả
          Pathnameecho D*Desktop Documents Downloads
          Tildeecho ~/home/me
          Số họcecho $((2 + 3 * 4))14 (chỉ số nguyên; ** là lũy thừa)
          Ngoặc nhọnecho file{A,B,C} · {1..5} · {a..e}fileA fileB fileC
          Tham sốecho $USERme
          Thay thế lệnhls -l $(which cp)output của lệnh trong $( )
          $ mkdir {2025..2026}-{01..12}   # tạo 24 thư mục theo tháng

          Trích dẫn (quoting) để kiểm soát mở rộng:

          • Nháy kép "...": tắt tách từ, wildcard, tilde, brace; vẫn giữ $, \, `. Dùng cho tên file có dấu cách: ls -l "two words.txt".
          • Nháy đơn '...': tắt mọi mở rộng.
          • Dấu thoát \: tắt ý nghĩa đặc biệt của một ký tự: echo "Giá: \$5.00".
          $ echo text ~/*.txt {a,b} $(echo foo) $((2+2)) $USER
$ echo "text ~/*.txt {a,b} $(echo foo) $((2+2)) $USER"
$ echo 'text ~/*.txt {a,b} $(echo foo) $((2+2)) $USER'

          Ctrl-LXóa màn hình (như clear)
          Ctrl-K / Ctrl-UCắt từ con trỏ tới cuối / đầu dòng
          Alt-D / Alt-BackspaceCắt một từ phía sau / phía trước

          Lệnh script ghi lại toàn bộ phiên terminal vào file, hữu ích khi cần lưu lại thao tác.

          09

          Quyền truy cập

          Linux là hệ thống nhiều người dùng. Mỗi file có chủ sở hữu (u), nhóm (g), và người khác (o); mỗi đối tượng có quyền r đọc, w ghi, x thực thi. Xem danh tính bằng id.

          -rwxr-x---  1 me  dev  ...  script.sh
# loại | u=rwx | g=r-x | o=---

          Với thư mục: r cho phép liệt kê, w cho phép tạo/xóa/đổi tên file bên trong, x cho phép cd vào.

          Bát phânQuyềnHay dùng cho
          7rwx
          6rw-
          5r-x
          4r--
          755rwxr-xr-xScript, thư mục
          644rw-r--r--File thường
          700 / 600chỉ chủ sở hữuFile riêng tư
          $ chmod 600 secret.txt
$ chmod u+x,go=rx script.sh   # dạng ký hiệu
$ umask                       # 0002: mặt nạ trừ bớt quyền mặc định
$ su -                        # mở shell của root
$ sudo apt update             # chạy một lệnh với quyền root
$ sudo chown bob:users file   # đổi chủ và nhóm
$ chgrp users file
$ passwd                      # đổi mật khẩu

          Quyền đặc biệt: setuid (4000, chạy với quyền chủ file, vd passwd), setgid (2000), sticky bit (1000, như ở /tmp: chỉ chủ mới xóa được file của mình).

          10

          Tiến trình

          Mỗi chương trình đang chạy là một tiến trình có số hiệu PID. Tiến trình đầu tiên (init/systemd) có PID 1.

          $ ps            # tiến trình của terminal này
$ ps x          # mọi tiến trình của tôi
$ ps aux        # mọi tiến trình của mọi user (có %CPU, %MEM)
$ top           # theo dõi trực tiếp; q để thoát
$ xlogo &       # chạy nền
$ jobs          # danh sách job
$ fg %1         # đưa job 1 lên tiền cảnh
  Ctrl-C  ngắt (INT)    Ctrl-Z  tạm dừng (TSTP)
$ bg %1         # cho job đang dừng chạy tiếp ở nền
$ kill 2345     # gửi TERM (15) tới PID 2345
$ kill -9 2345  # KILL: buộc dừng, dùng khi hết cách
$ killall xlogo # theo tên

          Trạng thái trong cột STAT: R đang chạy, S ngủ, D chờ I/O, T đã dừng, Z zombie, < ưu tiên cao, N ưu tiên thấp (nice). Tín hiệu hay gặp: HUP (1), INT (2), KILL (9), TERM (15), CONT (18), STOP (19). Lệnh liên quan: pstree, vmstat, shutdown.

          Phần 2

          Cấu hình và môi trường

          Sửa các file cấu hình điều khiển cách shell và hệ thống hoạt động.

          11

          Môi trường

          Shell lưu thông tin trong môi trường: biến môi trường, biến shell, alias, hàm.

          $ printenv | less     # biến môi trường
$ set | less          # cả biến shell và hàm
$ echo $HOME $PATH $SHELL $USER $PWD $LANG $EDITOR $PS1

          PATH là danh sách thư mục (cách nhau bởi :) mà shell tìm chương trình khi bạn gõ tên lệnh.

          Loại shellFile khởi động được đọc
          Login shell (đăng nhập)/etc/profile, rồi ~/.bash_profile hoặc ~/.bash_login hoặc ~/.profile
          Non-login (mở terminal trong GUI)/etc/bash.bashrc, ~/.bashrc

          Quy tắc: thêm thư mục vào PATH hoặc biến môi trường thì sửa ~/.bash_profile/~/.profile; mọi thứ khác (alias, hàm, umask) ghi vào ~/.bashrc. Luôn sao lưu trước khi sửa: cp .bashrc .bashrc.bak.

          # Thêm vào cuối ~/.bashrc
umask 0002
export HISTCONTROL=ignoredups
export HISTSIZE=1000
alias l.='ls -d .* --color=auto'
alias ll='ls -l --color=auto'
# Áp dụng ngay mà không cần mở terminal mới
$ source ~/.bashrc
          12

          Nhập môn trình soạn thảo vi

          vi (thường là vim) có mặt trên gần như mọi hệ Unix, nhẹ và nhanh, nên rất đáng học. Điểm mấu chốt: vi có chế độ. Khi mở là command mode (phím là lệnh), nhấn i để vào insert mode (gõ chữ), Esc để quay lại.

          PhímTác dụng
          :w · :q · :wq · :q!Lưu · thoát · lưu và thoát · thoát không lưu
          h j k lTrái, xuống, lên, phải
          w b · 0 $ · gg G · 5GTừ tiếp/trước · đầu/cuối dòng · đầu/cuối file · đến dòng 5
          i a A o OChèn trước / sau con trỏ / cuối dòng · mở dòng mới dưới / trên
          x · dd · dw · d$ · 5ddXóa ký tự · dòng · từ · tới cuối dòng · 5 dòng
          yy · p PChép dòng · dán sau / trước
          u · JHoàn tác · nối dòng
          /từ · nTìm · kết quả tiếp
          :%s/cũ/mới/g · :%s/cũ/mới/gcThay thế toàn file · có hỏi xác nhận
          :bn :bp · :e file · :r fileChuyển file · mở thêm file · chèn nội dung file khác

          Bị “kẹt” trong vi? Nhấn Esc vài lần rồi gõ :q!. Gõ vimtutor để có bài học tương tác 30 phút.

          13

          Tùy biến dấu nhắc lệnh

          Dấu nhắc được quy định bởi biến PS1. Các mã đặc biệt: \u user, \h host, \w thư mục đầy đủ, \W tên thư mục cuối, \t giờ, \d ngày, \$ ($ hoặc #), \n xuống dòng, \! số thứ tự lịch sử. Bọc mã điều khiển không in ra bằng \[ \].

          $ ps1_old="$PS1"                 # sao lưu
$ PS1="\A \h:\W\$ "               # 17:33 host:dir$
$ PS1="\[\033[0;32m\]\u@\h:\w\$\[\033[0m\] "   # màu xanh lá
$ PS1="$ps1_old"                 # khôi phục

          Mã màu ANSI: \033[0;30m đến \033[0;37m (đen, đỏ, xanh lá, nâu, xanh dương, tím, lục lam, xám); 1; cho bản sáng; 4Xm cho nền; \033[0m trả về mặc định. Muốn giữ lâu dài thì thêm PS1=... và export PS1 vào ~/.bashrc.

          Phần 3

          Công việc thường ngày và công cụ thiết yếu

          Quản lý gói, ổ đĩa, mạng, tìm file, nén/sao lưu, biểu thức chính quy và xử lý văn bản.

          14

          Quản lý gói phần mềm

          Hai họ chính: Debian (.deb: Debian, Ubuntu, Mint) và Red Hat (.rpm: Fedora, RHEL, CentOS, openSUSE). Gói được lấy từ kho (repository); công cụ cấp cao tự giải quyết phụ thuộc (dependency).

          ViệcDebian / UbuntuRed Hat / Fedora
          Tìm góiapt-cache search xyum search x
          Cài từ khoapt-get install xyum install x
          Cài từ filedpkg -i x.debrpm -i x.rpm
          Gỡapt-get remove xyum erase x
          Cập nhật tất cảapt-get update; apt-get upgradeyum update
          Liệt kê đã càidpkg -lrpm -qa
          Đã cài chưa?dpkg -s xrpm -q x
          Thông tin góiapt-cache show xyum info x
          File thuộc gói nàodpkg -S /bin/lsrpm -qf /bin/ls

          Ngày nay thường dùng apt (Ubuntu) và dnf (Fedora) thay cho apt-get/yum, cú pháp gần như giống hệt. Cần sudo cho các lệnh cài/gỡ.

          15

          Thiết bị lưu trữ

          Một thiết bị phải được gắn (mount) vào một thư mục trong cây file mới dùng được. Cấu hình gắn lúc khởi động nằm ở /etc/fstab.

          $ mount                          # liệt kê hệ thống file đang gắn
$ df -h                          # dung lượng từng phân vùng
$ sudo umount /dev/sdb1          # tháo ra (trước khi rút USB!)
$ sudo mount -t vfat /dev/sdb1 /mnt/usb
$ sudo tail -f /var/log/messages # cắm USB vào để xem tên thiết bị
$ sudo fdisk /dev/sdb            # chia phân vùng (m = menu)
$ sudo mkfs -t ext4 /dev/sdb1    # tạo hệ thống file (XÓA dữ liệu!)
$ sudo fsck /dev/sdb1            # kiểm tra và sửa lỗi
$ dd if=/dev/sdb of=usb.img      # sao chép thô cả thiết bị
$ genisoimage -o cd.iso -R -J ~/cd-files   # tạo file ISO
$ sudo mount -o loop image.iso /mnt/iso    # gắn ISO như một ổ đĩa
$ md5sum image.iso               # kiểm tra toàn vẹn

          Tên thiết bị: /dev/sda, /dev/sdb… là ổ đĩa (SATA/USB), /dev/sda1 là phân vùng 1. Ổ NVMe hiện đại có dạng /dev/nvme0n1p1.

          Cảnh báo: dd, mkfs, fdisk ghi thẳng vào thiết bị. Gõ nhầm tên ổ là mất dữ liệu. Luôn kiểm tra lại bằng lsblk trước.

          16

          Mạng

          $ ping -c 4 example.com          # kiểm tra kết nối (Ctrl-C để dừng nếu không có -c)
$ traceroute example.com         # các chặng gói tin đi qua
$ netstat -ie                    # giao diện mạng (nay: ip addr)
$ netstat -r                     # bảng định tuyến (nay: ip route)
$ wget https://example.com/file.tar.gz   # tải file không tương tác
$ ssh user@server                # đăng nhập từ xa an toàn
$ ssh server 'ls *' > list.txt   # chạy lệnh từ xa, lưu kết quả ở máy mình

          Tìm kiếm file

          locate nhanh nhưng dựa vào cơ sở dữ liệu cập nhật định kỳ (sudo updatedb). find chậm hơn nhưng tìm thật theo nhiều tiêu chí.

          $ locate bin/zip
$ find ~ -type f -name "*.jpg" -size +1M
$ find ~ -type d | wc -l            # đếm thư mục
$ find ~ -mmin -60                   # sửa trong 60 phút qua
$ find ~ \( -type f -not -perm 0600 \) -or \( -type d -not -perm 0700 \)
$ find . -name '*.bak' -delete       # hành động: xóa
$ find . -name '*.txt' -exec ls -l '{}' ';'   # chạy lệnh cho từng file
$ find . -name '*.txt' -exec ls -l '{}' +     # gộp thành một lần chạy
$ find . -name '*.txt' -ok rm '{}' ';'        # hỏi trước mỗi file
$ find . -name '*.txt' -print0 | xargs -0 ls -l
          • Test: -name, -iname, -type f|d|l, -size, -perm, -user, -mtime, -newer, -empty.
          • Toán tử: -and (mặc định), -or, -not, ngoặc \( \).
          • Tùy chọn: -maxdepth n, -mindepth n, -mount.

          Luôn chạy với -print (mặc định) để xem trước, rồi mới thêm -delete.

          Nén, đóng gói và sao lưu

          $ gzip foo.txt ; gunzip foo.txt.gz      # nén/giải nén (.gz)
$ gzip -c foo.txt > foo.gz ; zcat foo.gz
$ bzip2 foo.txt ; bunzip2 foo.txt.bz2   # nén tốt hơn, chậm hơn
$ tar cf  backup.tar  project/          # c=create f=file
$ tar tvf backup.tar                    # t=list v=verbose
$ tar xf  backup.tar                    # x=extract
$ tar czf backup.tgz project/           # z = nén gzip; j = bzip2
$ tar xzf backup.tgz project/docs       # chỉ giải nén một phần
$ zip -r project.zip project/ ; unzip project.zip
$ rsync -av source/ dest/               # đồng bộ, chỉ chép phần thay đổi
$ rsync -av --delete source/ dest/      # xóa file ở đích không còn ở nguồn

          Biểu thức chính quy (Regex)

          Regex là ký hiệu mô tả mẫu văn bản, dùng trong grep, sed, find -regex, less, vim… Nhiều ký hiệu giống wildcard nhưng ý nghĩa khác.

          Ký hiệuÝ nghĩaVí dụ
          .Một ký tự bất kỳ.zip
          ^ $Neo đầu / cuối dòng^zip$
          [abc] [^abc] [a-z]Tập ký tự, phủ định, khoảng^[A-Z]
          [[:digit:]] [[:space:]] [[:alnum:]]Lớp ký tự POSIX

          Xử lý văn bản

$ comm f1 f2           # so sánh 2 file đã sort: 3 cột

          Viết script đầu tiên

          Điều khiển luồng: rẽ nhánh với if

          Mỗi lệnh trả về exit status (xem bằng echo $?): 0 là thành công, khác 0 là lỗi. if kiểm tra exit status.

          if [ -f "$FILE" ]; then
  echo "$FILE là file thường"
elif [ -d "$FILE" ]; then
  echo "$FILE là thư mục"
else
  echo "Không tồn tại"; exit 1
fi
          Biểu thứcĐúng khi
          -e f -f f -d f -L fTồn tại · là file thường · thư mục · symlink
          -r f -w f -x f -s fĐọc được · ghi được · thực thi được · không rỗng
          f1 -nt f2f1 mới hơn f2
          -z s · -n sChuỗi rỗng · không rỗng
          s1 = s2 · s1 != s2So sánh chuỗi
          a -eq b -ne -lt -le -gt -geSo sánh số nguyên
          • [[ ]] là bản hiện đại của test/[ ]: hỗ trợ regex [[ $x =~ ^-?[0-9]+$ ]] và mẫu [[ $f == *.txt ]].
          • (( )) cho phép so sánh số tự nhiên: if ((INT % 2 == 0)); then.
          • Kết hợp: trong [ ] dùng -a -o !; trong [[ ]]/(( )) dùng && || !.
          • Toán tử điều khiển: mkdir temp && cd temp (chạy lệnh 2 nếu 1 thành công); [ -d temp ] || mkdir temp (chạy lệnh 2 nếu 1 thất bại).

          Gỡ lỗi

          Lỗi cú pháp hay gặp: thiếu dấu nháy đóng, thiếu ; trước then/do, thiếu fi/done, biến rỗng làm [ $x = 1 ] thành [ = 1 ] (sửa: [ "$x" = 1 ]).

if [[ -d "$dir_name" ]]; then

  else echo "không vào được '$dir_name'" >&2; exit 1; fi
else echo "không có thư mục '$dir_name'" >&2; exit 1; fi

          Kiểm thử: dùng stub (thay lệnh nguy hiểm bằng echo rm *), và chuẩn bị ca kiểm thử cho trường hợp bình thường, biên và lỗi.

          • Group command { } cần dấu cách sau { và ; trước }. Subshell chậm hơn và không đổi được biến của shell cha.
          • trap giúp script dọn file tạm khi bị Ctrl-C; sách khuyên tạo file tạm bằng mktemp để tránh bị tấn công dự đoán tên file.
          • Named pipe (FIFO) cho hai tiến trình không liên quan giao tiếp như một đường ống.
